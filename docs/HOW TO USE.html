OCB.GG · GLASS & DARK THEME · TEAMSPEAK 3

HOW TO USE

Besuche uns ↗

  1. Das Download-ZIP vollständig in einen neuen Ordner entpacken.
  2. Die enthaltene OCB.GG-Glass-Dark-Theme-TS3-v1.0.0-beta.9.ts3_style doppelklicken und im TeamSpeak-Paketinstaller installieren.
  3. TeamSpeak 3 öffnen: Extras → Optionen → Design. Das Theme ocb_obsidian auswählen. Falls angeboten, Stil Fusion verwenden.
  4. Für die weißen Sprechblasen unter Extras → Optionen → Design → Icon Pack zusätzlich ocb_white auswählen. Aktiv: weiß; inaktiv: gedimmt weiß/grau. Andere Icons kommen aus dem TS3-Standardpaket; spezielle Whisper-/Commander-Statusicons bleiben unterscheidbar.
  5. Übernehmen und den Client bei Bedarf neu starten.
  6. Wenn das Theme funktioniert, darf der entpackte Download gelöscht werden.

Probleme oder Deinstallation?

Öffnet sich kein Installer, die .ts3_style-Datei über „Öffnen mit“ dem Programm package_inst.exe im TeamSpeak-3-Installationsordner zuordnen.

Bei manuellen Updates zuerst die vorhandenen OCB-Dateien sichern. Die automatische Sicherungsfunktion des TS6-Installers ist hier nicht enthalten.

Zum Entfernen zuerst das Standardtheme auswählen, dann nur ocb_obsidian.qss, ocb_obsidian_chat.qss und den Ordner ocb_obsidian aus dem verwendeten TS3-Styles-Verzeichnis entfernen. Für die Icons zuerst ein Standard-Icon-Paket wählen, dann ausschließlich den Ordner ocb_white im TS3-gfx-Verzeichnis entfernen. Andere Themes erhalten.

TS3 enthält kein TS6-Dashboard und keine entsprechende Bildschirmfreigabe. Der Hostbanner wird vom Server eingestellt.
